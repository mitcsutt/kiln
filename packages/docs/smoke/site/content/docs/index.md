---

Smoke Toolbelt is a kit of plugins. Install one with `install <name>`, where <name> is the
plugin's name, or read about each under [Plugins](/docs/plugins).

## Install

```bash
agent plugin install <name>
```

Start with [Getting started](/docs/guides/getting-started).
