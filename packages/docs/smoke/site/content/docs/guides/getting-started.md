## Install a plugin

1. Add the marketplace.
2. Install a plugin by its <name>.

| Command          | What it does         |
| ---------------- | -------------------- |
| `install <name>` | installs one plugin  |
| `list`           | lists what's present |

```json title="settings.json"
{ "plugins": ["git"] }
```
