# 0004. Support React 18 and 19

- **Status:** Accepted
- **Date:** 2026-10-04

## Context

The source declares `react` `^18.3 || ^19`. It already runs a second test pass against React 18.3.1 through a private fixture package, and its authoring rules ban React 19-only APIs (ref-as-prop, `use()`).

## Decision

- Peer range `^18.3.0 || ^19.0.0` for `kiln-ui` and `kiln-forms`.
- CI runs the full test suite against both majors.
- The authoring rules keep requiring `forwardRef` and APIs available in both versions.

## Consequences

- Consumers still on React 18 can adopt Kiln.
- React 19-only conveniences wait for a future major that drops 18, and that change needs its own ADR.
