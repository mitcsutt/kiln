`List` and `Table` take `surface` (`none`, `surface` or `raised`) to set their rows on one sheet, with Card's edges, so they read as rows on a textured or coloured canvas. Highlighted, selected and hovered fills, categorical rails, muted rows, dividers and table captions sit inside the sheet's edge, and a sticky table header takes the sheet's fill. New component tokens: `--list-surface-bg`, `--list-surface-radius`, `--table-surface-bg` and `--table-surface-radius`.
