Add `@mitcsutt/kiln-eslint-config/docs-stories`, with the `kiln/docs-story` rule, for docs sites that show stories as copyable examples. A story tagged `docs` needs a JSDoc caption, a `render` that takes no args, imports from packages only and no `style`, and the tag goes on each story, never on the meta.
