Flightdeck: the light mode is now an electronic flight bag in daylight, with bright display panes set in a darker blue-grey bezel, so it no longer looks like Paper. Status tones read as annunciator capsules in both modes. At night the soft tones are saturated lenses with lit legends and the solid tones are the lit capsule; by day the soft tones are strong fills instead of pastels. Text, accent, line, selection and chart-axis colours are darkened by day so they hold contrast on the new bezel. The selected row is now true reverse video: a dark box with light ink by day and a bright box with dark ink at night, with status and accent text inside it set to stay readable. By day the panes are dimmed below paper-white, with well, pane and raised levels each a visible step apart.
