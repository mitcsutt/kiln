Ship agent skills in the `skills/` directory TanStack Intent reads, so `npx @tanstack/intent install` in a consumer project maps them into its agent instructions. `kiln-ui` covers installing and theming, composing layout with typed props, writing a custom theme, and the design rules. `kiln-forms` covers component mode, schema mode, custom fields, validation and view mode. The skills are built from the docs site's pages, so they match the docs for the installed version. Neither package has been released, so this changeset bumps nothing.
