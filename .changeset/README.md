# Changesets

Each Markdown file here describes a change to one or more published packages and how much to bump each one. Add one with `pnpm changeset` in any pull request that changes a published package. The release workflow turns them into version bumps and changelog entries.

See [CONTRIBUTING](../CONTRIBUTING.md#changesets) for when you need one, and [`docs/releasing.md`](../docs/releasing.md) for how releases happen.
