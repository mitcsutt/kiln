# Kiln workbench

This is where `@mitcsutt/kiln-ui`, `@mitcsutt/kiln-forms`, `@mitcsutt/kiln-dnd` and `@mitcsutt/kiln-charts` are built and checked in isolation. Guides, API tables and long-form docs live on the [docs site](https://kiln.mitchellsutton.com).

- **Theme** in the toolbar switches between Paper, Monograph, Ledger, Fiesta, Flightdeck and Riso. _All themes, side by side_ renders the story once per theme.
- **Mode** switches between light, dark and the system setting.
- Every component has a _Playground_ story with controls, plus stories for its real states.
- Every story runs as a test through the Vitest addon: it renders, its interactions pass, and axe finds no accessibility violations.

The tree matches the docs site: `UI` is `kiln-ui`, `Forms` is `kiln-forms`, `Drag and drop` is `kiln-dnd`, `Charts` is `kiln-charts`, and `Tooling` is the shared config packages.
