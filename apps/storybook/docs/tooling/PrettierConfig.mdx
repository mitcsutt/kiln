# Prettier config

`@mitcsutt/kiln-prettier-config` is the Prettier config every Kiln package and app formats with. It has no components to show here; the full guide is on the [docs site](https://kiln.mitchellsutton.com).

```sh
pnpm add -D @mitcsutt/kiln-prettier-config prettier
```

```json
{
  "prettier": "@mitcsutt/kiln-prettier-config"
}
```
