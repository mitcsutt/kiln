# Slipcast, the Kiln demo app

A pottery co-op app built with every component and hook in `@mitcsutt/kiln-ui`, `@mitcsutt/kiln-forms`, `@mitcsutt/kiln-dnd` and `@mitcsutt/kiln-charts`, in all four built-in themes. All its data is invented, and it makes no requests.

```bash
pnpm --filter @mitcsutt/kiln-demo dev   # http://localhost:5174
```

The docs site frames the built app at `/demo`. How it's organised, and the rule that every export must appear in it, are in [AGENTS.md](AGENTS.md) and [ADR 0046](../../docs/adr/0046-demo-app.md).
