---
title: useServerValues
description: Keep an edit form in step with server data that refreshes, without losing what the reader has typed.
exports: [useServerValues]
---

`useServerValues(form, data)` is for edit forms over data that can change underneath them: a query that refetches, a record someone else edits. When `data` changes, it becomes the new baseline. Fields the reader hasn't touched take the new values; fields they've edited keep their edits.

<Example of="useServerValues" />

After a save that rebaselines, a refetch returning the saved values leaves the form clean. `keepDirty` and `keepErrors` (both on by default) decide whether edits and visible errors survive a refresh. An error survives only on a value the refresh kept, and it stays visible whatever `errorVisibility` says. An error a submit or a step's Next had quieted isn't announced again; later edits to a field that was never quieted are still announced. A field that takes a new server value drops the error its old value had.
