---
title: useOptions
description: Options from a loader, debounced, cached and cancelled when superseded. The hook behind async comboboxes.
exports: [useOptions]
---

`useOptions(source, options)` turns a loader into options for a list: it debounces the query, aborts the previous request when a new one starts, and caches recent results (50 entries, keyed by the query and its dependencies). Static options pass straight through. The bound combobox and multi-select fields use it for `loadOptions`; use it directly for your own controls.

<Example name="forms/hooks/use-options/usage" />

The loader is called with `{ query, values, signal }` and returns options. It's read through a ref, so an inline loader with a new identity each render doesn't refetch; change `deps` to reload. `status` is `idle`, `loading`, `ready` or `error`.
