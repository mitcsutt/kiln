---
title: FormStatus
description: A polite status line. Unsaved changes, saving, saved or couldn't save.
exports: [FormStatus]
---

`FormStatus` says what's happening to the form's data in a polite live region, so screen readers hear it without losing their place: "Unsaved changes", "Saving…", "Saved", "Couldn't save". It pairs with [`useAutosave`](/docs/forms/hooks/use-autosave).

<Example name="forms/layouts/form-status/usage" />

Edit the notes and watch the status. `show` picks which states it reports. The text comes from the kit's `messages`.

## In a schema

```json
{ "content": "status" }
```
