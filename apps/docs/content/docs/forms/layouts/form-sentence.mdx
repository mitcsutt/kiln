`FormSentence` sets fields inside a sentence. Each field's label is hidden visually but kept for screen readers, and errors are listed below the sentence rather than breaking it, each linked to its field.

<Example name="forms/layouts/form-sentence/usage" />

Use it for short, low-stakes forms: a reminder, a filter, a goal. Never for long data entry. `label` names the group.

## In a schema

Text between fields is a `text` content node:

```json
{
  "layout": "sentence",
  "label": "Departure reminder",
  "children": [
    { "content": "text", "text": "Remind me at " },
    { "kind": "time", "name": "time", "label": "Time" },
    { "content": "text", "text": "." }
  ]
}
```
