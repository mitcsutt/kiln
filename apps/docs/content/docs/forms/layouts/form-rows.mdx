title: FormRows
description: Label-left rows. Every field inside lays its label and control out in columns, with no per-field setting.
exports: [FormRows]
---

`FormRows` turns every field inside into a row: label and description in a fixed column, the control beside them, and a rule between rows. Below `sm` each row stacks. It's the editor-panel settings row.

<Example name="forms/layouts/form-rows/usage" />

Group fields built on a fieldset (checkbox groups, radios, chips) keep their stacked layout for now.

## In a schema

```json
{ "layout": "rows", "children": [{ "kind": "text", "name": "name", "label": "Line name" }] }
```
