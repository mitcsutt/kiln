---
title: AmountField
description: A money field bound to a `number` path. Clearing it writes `null`.
exports: [FormAmountField]
---

It renders kiln-ui's [AmountField](/docs/ui/inputs/amount-field).

| Kind     | Shorthand          | Export            | Value            | Empty  |
| -------- | ------------------ | ----------------- | ---------------- | ------ |
| `amount` | `form.AmountField` | `FormAmountField` | `number \| null` | `null` |

<Example of="FormAmountField" />

`currency` is required. Use `unit="minor"` to store integer minor units (pence, cents), which is the safe way to keep money: never a float. View mode always shows the formatted amount.

## In a schema

```json
{
  "kind": "amount",
  "name": "topUp",
  "label": "Top-up",
  "currency": "GBP",
  "locale": "en-GB"
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
