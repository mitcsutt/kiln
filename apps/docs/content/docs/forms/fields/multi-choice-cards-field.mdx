It renders kiln-ui's [ChoiceCardsField](/docs/ui/inputs/choice-cards-field) with `type="multiple"`.

| Kind               | Shorthand                    | Export                      | Value                               | Empty |
| ------------------ | ---------------------------- | --------------------------- | ----------------------------------- | ----- |
| `multiChoiceCards` | `form.MultiChoiceCardsField` | `FormMultiChoiceCardsField` | an array of the options' value type | `[]`  |

<Example name="forms/fields/multi-choice-cards-field/usage" />

The same cards as the choice cards field, as a set of checkboxes.

## In a schema

```json
{
  "kind": "multiChoiceCards",
  "name": "extras",
  "label": "Add-ons",
  "options": [
    {
      "value": "bike",
      "label": "Bike space"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
