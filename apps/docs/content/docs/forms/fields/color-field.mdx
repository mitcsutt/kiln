It renders kiln-ui's [ColorField](/docs/ui/inputs/color-field).

| Kind    | Shorthand         | Export           | Value                | Empty |
| ------- | ----------------- | ---------------- | -------------------- | ----- |
| `color` | `form.ColorField` | `FormColorField` | `string` (`#rrggbb`) | `''`  |

<Example name="forms/fields/color-field/usage" />

View mode shows the matching swatch's name beside the hex code.

## In a schema

```json
{
  "kind": "color",
  "name": "lineColour",
  "label": "Line colour",
  "swatches": [
    {
      "value": "#1f6f8b",
      "label": "Harbour blue"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
