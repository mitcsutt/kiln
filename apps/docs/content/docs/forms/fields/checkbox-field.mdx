It renders kiln-ui's [CheckboxField](/docs/ui/inputs/checkbox-field).

| Kind       | Shorthand            | Export              | Value     | Empty   |
| ---------- | -------------------- | ------------------- | --------- | ------- |
| `checkbox` | `form.CheckboxField` | `FormCheckboxField` | `boolean` | `false` |

<Example name="forms/fields/checkbox-field/usage" />

A `required` rule on a checkbox means it must be ticked.

## In a schema

```json
{
  "kind": "checkbox",
  "name": "terms",
  "label": "I've read the terms of carriage"
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
