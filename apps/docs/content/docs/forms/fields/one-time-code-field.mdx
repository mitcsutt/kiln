It renders kiln-ui's [OneTimeCodeField](/docs/ui/inputs/one-time-code-field).

| Kind          | Shorthand               | Export                 | Value    | Empty |
| ------------- | ----------------------- | ---------------------- | -------- | ----- |
| `oneTimeCode` | `form.OneTimeCodeField` | `FormOneTimeCodeField` | `string` | `''`  |

<Example of="FormOneTimeCodeField" />

`submitOnComplete` submits the form as soon as the last cell is filled, which suits a sign-in screen with nothing else on it.

## In a schema

```json
{
  "kind": "oneTimeCode",
  "name": "code",
  "label": "Verification code",
  "length": 6
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
