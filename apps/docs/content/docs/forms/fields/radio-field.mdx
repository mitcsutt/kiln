It renders kiln-ui's [RadioGroupField](/docs/ui/inputs/radio-group-field).

| Kind    | Shorthand         | Export           | Value                              | Empty  |
| ------- | ----------------- | ---------------- | ---------------------------------- | ------ |
| `radio` | `form.RadioField` | `FormRadioField` | the options' value type, or `null` | `null` |

<Example of="FormRadioField" />

Exported as `FormRadioField`, named after its kind. For five or more options, a select field takes less room.

## In a schema

```json
{
  "kind": "radio",
  "name": "deck",
  "label": "Deck",
  "options": [
    {
      "value": "upper",
      "label": "Upper deck"
    },
    {
      "value": "lower",
      "label": "Lower deck"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
