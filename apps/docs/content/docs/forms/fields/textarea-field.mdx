It renders kiln-ui's [TextareaField](/docs/ui/inputs/textarea-field).

| Kind       | Shorthand            | Export              | Value    | Empty |
| ---------- | -------------------- | ------------------- | -------- | ----- |
| `textarea` | `form.TextareaField` | `FormTextareaField` | `string` | `''`  |

<Example of="FormTextareaField" />

`autoResize` grows it with its content up to `maxRows`.

## In a schema

```json
{
  "kind": "textarea",
  "name": "notes",
  "label": "Notes for the crew",
  "maxLength": 300,
  "showCount": true
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
