It renders kiln-ui's [CheckboxGroupField](/docs/ui/inputs/checkbox-group-field).

| Kind            | Shorthand                 | Export                   | Value                               | Empty |
| --------------- | ------------------------- | ------------------------ | ----------------------------------- | ----- |
| `checkboxGroup` | `form.CheckboxGroupField` | `FormCheckboxGroupField` | an array of the options' value type | `[]`  |

<Example name="forms/fields/checkbox-group-field/usage" />

`selectAllLabel` adds a parent checkbox; `columns` lays a long list out in a grid.

## In a schema

```json
{
  "kind": "checkboxGroup",
  "name": "facilities",
  "label": "Facilities you need",
  "options": [
    {
      "value": "step-free",
      "label": "Step-free access"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
