title: NumberField
description: A number field bound to a `number` path. Clearing it writes `null`, never `NaN` or `''`.
exports: [FormNumberField]
---

It renders kiln-ui's [NumberField](/docs/ui/inputs/number-field).

| Kind     | Shorthand          | Export            | Value            | Empty  |
| -------- | ------------------ | ----------------- | ---------------- | ------ |
| `number` | `form.NumberField` | `FormNumberField` | `number \| null` | `null` |

<Example of="FormNumberField" />

Model a number that can be empty as `number | null`. It binds to a plain `number` path too, but clearing it still writes `null`, and a `required` rule reports it. In view mode the value is formatted with the field's own `formatOptions` and `locale`.

## In a schema

```json
{
  "kind": "number",
  "name": "passengers",
  "label": "Passengers",
  "min": 1,
  "max": 9
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
