---
title: DateRangeField
description: Two ISO dates bound to a `{ start, end }` path.
exports: [FormDateRangeField]
---

It renders kiln-ui's [DateRangeField](/docs/ui/inputs/date-range-field).

| Kind        | Shorthand             | Export               | Value                            | Empty                    |
| ----------- | --------------------- | -------------------- | -------------------------------- | ------------------------ |
| `dateRange` | `form.DateRangeField` | `FormDateRangeField` | `{ start: string; end: string }` | `{ start: '', end: '' }` |

<Example name="forms/fields/date-range-field/usage" />

Natively submitted, it sends `name.start` and `name.end`. View mode joins the two formatted dates with an en dash.

## In a schema

```json
{
  "kind": "dateRange",
  "name": "trip",
  "label": "Travel dates",
  "startLabel": "First day",
  "endLabel": "Last day"
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
