It renders kiln-ui's [SegmentedField](/docs/ui/inputs/segmented-field).

| Kind        | Shorthand             | Export               | Value                              | Empty  |
| ----------- | --------------------- | -------------------- | ---------------------------------- | ------ |
| `segmented` | `form.SegmentedField` | `FormSegmentedField` | the options' value type, or `null` | `null` |

<Example of="FormSegmentedField" />

A segmented control always shows one segment selected, so give the path a sensible default.

## In a schema

```json
{
  "kind": "segmented",
  "name": "journey",
  "label": "Journey",
  "options": [
    {
      "value": "single",
      "label": "Single"
    },
    {
      "value": "return",
      "label": "Return"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
