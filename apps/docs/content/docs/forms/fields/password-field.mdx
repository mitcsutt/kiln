---
title: PasswordField
description: A password field with a show and hide toggle, bound to a `string` path.
exports: [FormPasswordField]
---

It renders kiln-ui's [PasswordField](/docs/ui/inputs/password-field).

| Kind       | Shorthand            | Export              | Value    | Empty |
| ---------- | -------------------- | ------------------- | -------- | ----- |
| `password` | `form.PasswordField` | `FormPasswordField` | `string` | `''`  |

<Example name="forms/fields/password-field/usage" />

`autoComplete` is required. In view mode it shows a fixed-length mask, so the view never reveals the password or its length.

## In a schema

```json
{
  "kind": "password",
  "name": "password",
  "label": "Password",
  "autoComplete": "new-password"
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
