It renders kiln-ui's [TextField](/docs/ui/inputs/text-field).

| Kind   | Shorthand        | Export          | Value    | Empty |
| ------ | ---------------- | --------------- | -------- | ----- |
| `text` | `form.TextField` | `FormTextField` | `string` | `''`  |

<Example of="FormTextField" />

`type` (`text`, `email`, `tel`, `url` or `search`) sets the keyboard and autofill only. Validation comes from your rules or schema, so `type="email"` doesn't check the address by itself. A text field can't bind to a union like `'admin' | 'member'`: a text box would write any string, so use a select, radio or segmented field.

## In a schema

```json
{
  "kind": "text",
  "name": "destination",
  "label": "Destination"
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
