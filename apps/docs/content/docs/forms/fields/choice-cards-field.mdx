---
title: ChoiceCardsField
description: One choice from a handful of cards, for options that need a sentence or a price each.
exports: [FormChoiceCardsField]
---

It renders kiln-ui's [ChoiceCardsField](/docs/ui/inputs/choice-cards-field) with `type="single"`.

| Kind          | Shorthand               | Export                 | Value                              | Empty  |
| ------------- | ----------------------- | ---------------------- | ---------------------------------- | ------ |
| `choiceCards` | `form.ChoiceCardsField` | `FormChoiceCardsField` | the options' value type, or `null` | `null` |

<Example name="forms/fields/choice-cards-field/usage" />

`optionMeta` adds a figure to each card (usually the price), computed from the option's value.

## In a schema

```json
{
  "kind": "choiceCards",
  "name": "plan",
  "label": "Pass",
  "options": [
    {
      "value": "month",
      "label": "Month",
      "description": "Renews automatically"
    }
  ]
}
```

## API

Every bound field also takes `name` (a path to a value it can hold), `validators`, `listeners` and `defaultValue`, plus `warn` for advice that never blocks. `excluded` keeps a field visible but leaves it out of validation and submits its default.
