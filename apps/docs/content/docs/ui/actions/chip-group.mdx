`ChipGroup` is one field made of chips: `type="multiple"` for several of a set, `type="single"` for at most one (pressing the chosen chip again clears it). Arrow keys move between chips, and `name` adds hidden inputs so it submits with a native form. Give it a name with a `Fieldset` legend or an `aria-label`.

## Errors

Inside a `Fieldset` with an `error`, the chips take the critical edge and `aria-invalid`. Use [ChipGroupField](/docs/ui/inputs/chip-group-field) for the label, description and error in one component.
