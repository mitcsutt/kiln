---
title: ModeToggle
description: Switches the colour mode between light, dark and the system setting, through the theme provider.
exports: [ModeToggle]
---

`ModeToggle` reads and sets the mode from `useTheme()`, so it needs a `ThemeProvider` above it, and it throws without one: a toggle that silently does nothing is worse than a loud error. The choice is remembered, and `themeScript` applies it before the first paint on the next visit.

<Example name="ui/actions/mode-toggle/usage" />

The toggles above change these docs' real mode. `variant="icon"` (the default) is one quiet button that cycles light, dark and system; its icon shows the current mode, and its accessible name says what a press switches to. `variant="segmented"` shows all three at once, for a settings page or a footer.
