---
title: ToggleChip
description: An independent on-off filter that sits in a row with others, with an optional count.
exports: [ToggleChip]
---

A `ToggleChip` is a pressed or unpressed button, announced as a toggle (`aria-pressed`). Each chip in a row is independent, so a row of them is a set of filters, not a choice of one. For a set of chips that act together (one of, or several of, one field), use [ChipGroup](/docs/ui/actions/chip-group).

<Example name="ui/actions/toggle-chip/filters" />

`count` shows how many results the filter covers. Control it with `pressed` and `onPressedChange`, or let it manage itself with `defaultPressed`.
