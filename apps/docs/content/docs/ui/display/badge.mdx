A `Badge` is status: what state a thing is in right now. For categories and metadata (a line, a facility, a topic) use a [Tag](/docs/ui/display/tag), which is quieter.

<Example name="ui/display/badge/usage" />

`tone` carries the meaning: `positive`, `caution`, `critical` and `info` for status, `accent` for something current, `neutral` for counts. `variant` is `soft` (the default), `solid` for the one badge that must shout, or `outline`. `dot` adds a leading dot, for live states.

Keep badges to a word or two, and don't use colour alone: "Delayed" in the caution tone says it twice.
