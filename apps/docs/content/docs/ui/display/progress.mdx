title: Progress
description: How far along a task is, like an upload or a sync, or that it's under way when nobody knows how far.
exports: [Progress]
---

`Progress` shows a task moving toward done. For a quantity against a limit (seats taken, storage used), use [Meter](/docs/ui/display/meter): a meter is a level, not a journey.

<Example name="ui/display/progress/usage" />

`value={null}` is indeterminate: the task is under way but its length is unknown. `label` names the bar, `showValue` prints the percentage (change the text with `formatValue`), and `tone` marks success or trouble.
