`EmptyState` replaces content that doesn't exist yet: no saved routes, no results for a filter. It's typographic: a title that says what's empty, a sentence that says what to do, and one action that does it.

<Example name="ui/display/empty-state/usage" />

`framed` marks the frame with printer's crop marks rather than a dashed box. `align="center"` suits an empty state that fills a region; left-aligned (the default) suits one inside a page. `media` adds an illustration, and `titleAs` sets the heading level.
