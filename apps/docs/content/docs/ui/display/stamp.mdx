`Stamp` is a verdict, stamped on the thing it judges: a refunded ticket, a void invoice. It's decorative but deliberate, so use one per object.

<Example of="Stamp" />

It reads as its text. When the word needs more context, pass an `aria-label` ("Ticket 0417 refunded"). `placement="corner"` pins it to the corner of its positioned parent, and `rotate` sets the angle in degrees.
