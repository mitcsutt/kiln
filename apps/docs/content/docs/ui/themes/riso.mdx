_A two-drum risograph zine._ A riso print can't do gradients or soft shadows. It does flat spot ink, screen tints and the occasional misregistration, so that is all Riso uses: spot inks on bright white stock, set in a typeface drawn from handwriting.

## Use it

```tsx
import '@mitcsutt/kiln-ui/styles.css'
import '@mitcsutt/kiln-ui/themes/riso.css'
import { ThemeProvider } from '@mitcsutt/kiln-ui'

;<ThemeProvider theme="riso" defaultMode="light">
  …
</ThemeProvider>
```

Riso's face is declared in its own stylesheet, so it costs nothing unless you import it. It's light-first, and dark mode is a reverse print: the blue drum floods the page.

## The idea, applied

- **Colour.** By day, the classic two-drum pairing on bright white stock: Blue 3005 U is the accent and a deep blue the text colour, and Sunflower 116 U marks where you are (the current page, the highlight, the selection). Cards are bare stock with a hairline edge, and only sunken wells take a blue screen tint. Night is a reverse print: the blue drum floods the page, cards and type knock out to stock, and the accent is fluorescent pink. Focus rings are the blue drum in both modes.
- **Type.** Shantell Sans for every role except code, drawn from the artist Shantell Martin's own handwriting. It has no tabular figures, so numerals are not column-aligned. Atkinson Hyperlegible Mono is for code. A 1.25 ratio.
- **Shape.** Hand-cut and mixed: generous radii on actions and surfaces, smaller radii on fields, and pill chips.
- **Depth.** A fill change, with no shadow on static surfaces. The one misregistered moment is a hard pink offset on floating layers, as if the second drum printed slightly off.
- **Motion.** A mild spring: things land with a small overshoot.
