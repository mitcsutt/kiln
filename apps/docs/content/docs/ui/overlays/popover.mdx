`Popover` opens a floating panel beside its trigger. It's non-modal: the rest of the page stays usable, and it closes on Escape or a click outside, returning focus to the trigger.

<Example of="Popover" />

Give `Popover.Content` an `aria-label` (or a heading inside it). `arrow` draws a pointer to the trigger. For a hint on hover, use a [Tooltip](/docs/ui/overlays/tooltip); for a list of commands, a [DropdownMenu](/docs/ui/overlays/dropdown-menu).
