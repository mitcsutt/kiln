`DropdownMenu` holds the actions you don't need to see all the time: a row's options, a sort order. It's Radix Menu underneath, so arrow keys, typeahead, Home, End and Escape all work.

<Example name="ui/overlays/dropdown-menu/usage" />

- `DropdownMenu.Item` is a command. It takes a `leadingIcon`, a `shortcut` hint, and `tone="critical"` for destructive commands.
- `DropdownMenu.CheckboxItem` toggles a setting; `DropdownMenu.RadioGroup` with `RadioItem`s picks one of a set.
- `Label`, `Separator` and `Group` organise longer menus, and `Sub`, `SubTrigger` and `SubContent` nest one.
