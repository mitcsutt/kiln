`Sheet` is a dialog that slides in from the side or the bottom. It's built on Radix Dialog, so it traps focus, closes on Escape or a tap on the scrim, locks page scroll and returns focus to its trigger.

<Example of="Sheet" />

`side` is `right` (the default), `left` or `bottom`, and takes a responsive value: `{ base: 'bottom', md: 'right' }` is a bottom sheet on phones and a drawer from 48em. A bottom sheet shows a grab handle. `size` sets the width of a side sheet or the maximum height of a bottom one. The mobile navigation in these docs is a `Sheet`.
