exports: [StatusDot]
---

`StatusDot` pairs a tone with a word, so status never depends on colour alone. For "happening now", use a [LiveIndicator](/docs/ui/feedback/live-indicator).

<Example of="StatusDot" />

`labelHidden` keeps the label for screen readers only, for dense tables where a column header already explains the dots.
