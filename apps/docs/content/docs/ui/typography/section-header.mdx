`SectionHeader` puts a section's title, an optional kicker and description, and its actions in one component, so they align with each other and wrap together on a phone. The title, kicker and description are grouped in an `<hgroup>`.

<Example of="SectionHeader" />

`level` and `size` work as on [Heading](/docs/ui/typography/heading). `divider` rules it off from what follows. `titleId` sets the heading's `id`, so a `<section aria-labelledby>` can point at it.

Use a kicker sparingly: a short label over one title is useful, a tracked label over every section on the page is noise.
