`Amount` is a [Numeral](/docs/ui/typography/numeral) for money. It formats the currency for the locale, uses tabular figures and a true minus sign, and can show negatives in parentheses like a ledger.

<Example of="Amount" />

- `currency` (default `AUD`) and `locale` (default `en-AU`). A currency the locale has no symbol for shows its narrow symbol when that's unambiguous, and its ISO code otherwise.
- `accounting` shows a negative as `($1,234.50)` in the critical tone.
- `showSign` adds a plus to positive values; `tone="auto"` colours both signs.
- `compact` abbreviates large values (`$2.5M`), and `precision` sets the decimal places.
