`SelectField` is a [Field](/docs/ui/inputs/field) around a [Select](/docs/ui/inputs/select). Select props (`options`, `groups`, `value`, `placeholder`) go to the select.

<Example name="ui/inputs/select-field/usage" />

With a `placeholder` and no value, nothing is chosen until the reader picks, which is usually right: a pre-chosen default is easy to submit by accident.
