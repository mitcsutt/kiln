`AmountField` is a [Field](/docs/ui/inputs/field) around an [AmountInput](/docs/ui/inputs/amount-input). `currency` is required, and sets the decimal places and the symbol.

<Example of="AmountField" />

Store money in minor units (`unit="minor"`, integer pence) so it's never a float.
