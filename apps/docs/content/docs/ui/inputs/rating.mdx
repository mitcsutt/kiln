`Rating` is a radio group whose radios are stars, so it's one tab stop and the arrow keys move and choose. Stars up to the rating fill with the accent, and hovering previews a rating before you choose. `clearable` lets pressing the chosen star again clear it.

<Example name="ui/inputs/rating/usage" />

`max` sets the number of stars, and `itemLabel` names each one for screen readers.
