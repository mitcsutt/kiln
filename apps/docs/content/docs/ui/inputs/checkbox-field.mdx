`CheckboxField` puts the label to the right of the checkbox, where people look for it, with help and an error underneath. Use it for a single yes or no: consent, a preference.

<Example name="ui/inputs/checkbox-field/usage" />

For several related checkboxes, use a [CheckboxGroupField](/docs/ui/inputs/checkbox-group-field), which gives the set one legend.
