---
title: Switch
description: An on-off setting that takes effect at once.
exports: [Switch]
---

`Switch` is for a setting that applies immediately, like turning alerts on. For a choice that's submitted with a form, a checkbox says more clearly that nothing happens until you submit. `label` puts a label beside it; inside a settings list, use [SwitchField](/docs/ui/inputs/switch-field).
