`CheckboxGroup` lays out a set of checkboxes from `options` (or `CheckboxGroup.Item` children) and holds their values as one array. `selectAllLabel` adds a parent checkbox that goes indeterminate when only some are chosen. `columns` lays a long set out in a responsive grid.
