`NumberField` is a [Field](/docs/ui/inputs/field) around a [NumberInput](/docs/ui/inputs/number-input): a spinbutton formatted for the locale, with `min`, `max`, `step` and an optional stepper.

<Example name="ui/inputs/number-field/usage" />

The value is `number | null` (empty is `null`, not `0`). `clampOnBlur` pulls an out-of-range value back inside when the reader leaves the field.
