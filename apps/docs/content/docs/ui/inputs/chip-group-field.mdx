`ChipGroupField` is a [ChipGroup](/docs/ui/actions/chip-group) under a [Fieldset](/docs/ui/inputs/fieldset) legend. `type="multiple"` picks several, `type="single"` at most one.

<Example name="ui/inputs/chip-group-field/usage" />

Chips suit short labels. For choices that need a sentence each, use a [CheckboxGroupField](/docs/ui/inputs/checkbox-group-field).
