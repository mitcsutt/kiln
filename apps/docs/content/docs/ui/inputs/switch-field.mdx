`SwitchField` is the row you'd find in a settings list: the label and its description on the left, the [Switch](/docs/ui/inputs/switch) on the right, an error underneath. The whole label is part of the target.

<Example of="SwitchField" />

Switches take effect at once. For a choice that waits for a form to be submitted, use a [CheckboxField](/docs/ui/inputs/checkbox-field).
