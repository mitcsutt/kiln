`SegmentedField` is a [SegmentedControl](/docs/ui/actions/segmented-control) with a label, description and error. It always has one segment selected, so it suits choices with a sensible default.

<Example name="ui/inputs/segmented-field/usage" />

`name` adds a hidden input for native form submission. `fullWidth` stretches the segments across the field.
