`ComboboxField` is a [Field](/docs/ui/inputs/field) around a [Combobox](/docs/ui/inputs/combobox). Combobox props (`options`, `multiple`, `creatable`, `loading`) go to the combobox.

<Example name="ui/inputs/combobox-field/usage" />

With `creatable`, the reader can add a value that isn't in the list.
