`Select` is Radix Select with Kiln's look: a button that opens a listbox, with typeahead, arrow keys and grouped options. Pass `options`, or `groups` for labelled sections. `name` adds a hidden input so it submits with a native form. For a labelled select, use [SelectField](/docs/ui/inputs/select-field).

<Example of="Select" />

For more than a dozen options, or options people know by name, a [Combobox](/docs/ui/inputs/combobox) that filters as you type is faster.
