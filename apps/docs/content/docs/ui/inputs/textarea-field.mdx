`TextareaField` is a [Field](/docs/ui/inputs/field) around a [Textarea](/docs/ui/inputs/textarea). Textarea props and the ref go to the `<textarea>`.

<Example name="ui/inputs/textarea-field/usage" />

`autoResize` grows it up to `maxRows`. `showCount` with `maxLength` counts down the characters left.
