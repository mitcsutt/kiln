`TextField` is a [Field](/docs/ui/inputs/field) around an [Input](/docs/ui/inputs/input): the label, description, error and warning wired to the control in one component. Input props (`value`, `type`, `autoComplete`, `leading`, `numeric`) and the ref go to the `<input>`.

<Example of="TextField" />

`onValueChange` gives you the string without the event. `showCount` with `maxLength` shows how many characters are left. Use the right `type` and `autoComplete` (`email`, `tel`, `postal-code`): phones show the right keyboard, and browsers can fill the field in.

To bind it to form state and validation, use kiln-forms' [FormTextField](/docs/forms/fields/text-field), which renders this component.
