`Checkbox` is Radix Checkbox with Kiln's look. `checked` can be `true`, `false` or `'indeterminate'`, for a parent that controls a set where only some are on. It needs a label: use [CheckboxField](/docs/ui/inputs/checkbox-field), a `Field`, or an `aria-label`.
