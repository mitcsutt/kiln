`CheckboxGroupField` is a [CheckboxGroup](/docs/ui/inputs/checkbox-group) under a [Fieldset](/docs/ui/inputs/fieldset) legend. The error and warning describe the set, not one box.

<Example name="ui/inputs/checkbox-group-field/usage" />

`selectAllLabel` adds a parent checkbox, and `columns` lays a long set out in a grid.
