`RadioGroupField` lays out a [RadioGroup](/docs/ui/inputs/radio-group) from `options` under a [Fieldset](/docs/ui/inputs/fieldset) legend, each option with a label and an optional description. Arrow keys move and select.

<Example of="RadioGroupField" />

`orientation="horizontal"` puts short options in a row. For five or more options, a [SelectField](/docs/ui/inputs/select-field) takes less room; for options that need a price or a sentence, [ChoiceCardsField](/docs/ui/inputs/choice-cards-field).
